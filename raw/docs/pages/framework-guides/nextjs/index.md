# Next.js

Last updated Aug 25, 2026|Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/pages/framework-guides/nextjs/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

[Next.js ↗︎](https://nextjs.org) is an open-source React framework for creating websites and applications.

Cloudflare recommends [vinext on Workers](https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/) for full-stack Next.js applications, including server-side rendering, React Server Components, Server Actions, route handlers, and middleware.

To deploy a static Next.js export to Pages, refer to [Static site](https://developers.cloudflare.com/pages/framework-guides/nextjs/deploy-a-static-nextjs-site/).
