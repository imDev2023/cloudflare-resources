# Product name and pluralization

Last updated Aug 20, 2026|Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/style-guide/style-and-grammar/formatting/product-name-and-pluralization/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

Product names should follow a noun-verb agreement such that the verb is singular.

Examples:

- Cloudflare Pages enables/allows.
- Cloudflare Workers executes/propagates.
