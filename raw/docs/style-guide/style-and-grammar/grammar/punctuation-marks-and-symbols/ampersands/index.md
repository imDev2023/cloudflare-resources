# Ampersands

Last updated Aug 20, 2026|Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/style-guide/style-and-grammar/grammar/punctuation-marks-and-symbols/ampersands/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

Do not use ampersands, except where space is limited in the UI and where they are part of existing proper names.
