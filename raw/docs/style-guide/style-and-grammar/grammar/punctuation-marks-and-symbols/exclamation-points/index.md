# Exclamation points

Last updated Aug 20, 2026|Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/style-guide/style-and-grammar/grammar/punctuation-marks-and-symbols/exclamation-points/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

Avoid using exclamation points in most writing!

Exclamation points are appropriate for success messages or screens in the UI.
