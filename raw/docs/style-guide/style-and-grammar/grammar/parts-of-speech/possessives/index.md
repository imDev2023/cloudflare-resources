# Possessives

Last updated Aug 20, 2026|Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/style-guide/style-and-grammar/grammar/parts-of-speech/possessives/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

In general, avoid the 's construction to show possession by an inanimate object as doing so personifies the object.

Example: *the device's address*.
