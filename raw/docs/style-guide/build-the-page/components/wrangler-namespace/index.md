The `WranglerNamespace` component documents the available commands for a given namespace.

This is generated using the Wrangler version in the [`cloudflare-docs` repository ↗︎](https://github.com/cloudflare/cloudflare-docs/blob/production/package.json).

## Import

```mdx
import { WranglerNamespace } from "~/components";
```

## Usage

```mdx
import { WranglerNamespace } from "~/components";

<WranglerNamespace namespace="d1" />

<WranglerNamespace namespace="hyperdrive" cfNamespace="hyperdrive" />
```

## Arguments

- `namespace` `string` required
  - The namespace to pull the related commands from ( `d1`, `hyperdrive`).
- `headingLevel` `number` (default: 2) optional
  - The heading level that the commands should be added at on the page, i.e `2` for `h2`.
- `cfNamespace` `string` optional
  - A reviewed Cloudflare CLI namespace without the `cf` prefix. Supplying this prop displays one shared CLI selector for the namespace. Explain differences between the command families in the surrounding page content.
